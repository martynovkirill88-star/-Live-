# Чепушка Live для iPhone

Клиент на SwiftUI и WebKit. Каталог, вход, каналы и видео используют действующий сайт Чепушка Live. Мобильное оформление хранится в App/mobile.js, плеер загружается с сайта.

GitHub Actions собирает IPA для iPhone на macOS. Артефакт называется ChepushkaLive-unsigned. Для установки его нужно подписать. Локальная сборка проекта начинается с команды xcodegen generate.
