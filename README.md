# Чепушка Live для iPhone

Лента, каналы и экран просмотра собраны на SwiftUI. Плеер сайта и его ресурсы входят в IPA и открываются как локальный компонент WebKit. Каталог, каналы, обложки, кадры предпросмотра и видеопотоки загружаются с Чепушка Live. Подписки и закладки хранятся на устройстве.

Требуется iOS 16 или новее. GitHub Actions собирает неподписанный IPA для iPhone. Для установки IPA требуется подпись.
