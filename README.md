# Чепушка Live для iPhone

Интерфейс собран на SwiftUI, воспроизведение использует AVPlayer и HLS. Каталог, каналы, изображения и потоки загружаются с Чепушка Live. Подписки и сохранённое хранятся на устройстве.

Требуется iOS 16 или новее. GitHub Actions собирает неподписанный IPA для iPhone. Для установки IPA требуется подпись.
